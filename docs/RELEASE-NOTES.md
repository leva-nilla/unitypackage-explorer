# UnityPackage Explorer v0.1.0

初回プレビュー版です。Windows 11 x64で、Unityを起動せずにZIP内のUnityPackageやPrefabを確認できます。

## 主な内容

- ZIPを展開せずにUnityPackageの構成、検索、種類別一覧、画像を確認。
- Prefabの階層、参照FBXと基本の色テクスチャを近似表示。
- ドラッグ＆ドロップ、従来の右クリックメニュー、スタートメニューと「送る」から起動。
- Unityに近いフライスルー操作、プレビュー後のZIP分類移動。
- ユーザー単位のセットアップ、更新、アンインストール。既定アプリの関連付けは変更しません。
- .NET 10と必要なVisual C++実行環境を同梱。UnityやSDKの導入は不要です。
- MIT License。試せる自作サンプルはCC0です。

## 表示の制約

3Dは素材整理用の近似表示です。Unityのシェーダー、物理、独自コンポーネント、ボーン変形は再現しません。個別メッシュの対応が取れない場合はFBX全体を表示し、重複した参照を省略します。スキン付きFBXはPrefabルートのTransformで配置します。

FBXとUnityの材質対応情報が足りない場合や、ネストPrefabの材質上書きをRenderer・スロットへ対応付けられない場合は色を反映できません。確認できた階層と形を表示し、読み込み結果欄に理由と参照情報を示します。

Explorerのプレビュー欄とWindows 11の新しい右クリックメニューはこの版には含みません。右クリックの「その他のオプションを確認」から開いてください。

インストーラーとアプリは未署名です。Windows SmartScreenが発行元を確認できないと表示する場合があります。ダウンロード元と添付のSHA-256を確認してください。

## 確認

Releaseの自動テスト80件と旧版移行・解除のPowerShellテストを実行しています。Windows CIではセットアップ生成、新規導入、SDK/.NETのPATHに依存しない起動、登録解除を確認します。

手元の3つの非配布ZIPで155件のPrefabを解析し、代表Prefabの実画面、階層、読み込み結果を確認しました。すべての色やUnity上の完成形の再現を保証するものではありません。購入素材は配布物・公開画像に含めていません。

公開用の画面は[自作サンプル](../tools/samples/README.md)を実アプリで撮影したものです。
